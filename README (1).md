# rain-tg-bot

Rain webhook'unu alip Telegram grubuna sablonlu mesaj olarak gonderir.

Ortam degiskenleri: TG_TOKEN, TG_CHAT_ID, RAIN_SECRET, SITE_NAME, SITE_URL

Render ayarlari: Language Node, Build `npm install`, Start `npm start`.
Panelde webhook adresi: https://SERVISADIN.onrender.com/rain-webhook
